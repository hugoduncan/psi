🔁 Workflow prompts that create an artifact/task should not let downstream steps consume the creator's raw handoff as identity. Add an explicit extractor/validator step that accepts exactly one machine-readable path/id, yields only that value, and routes malformed handoffs to a terminal stop. Task 218 used `extract-task-path` between `select-and-create` and every design/plan/implement/review delegate; tests then locked that all downstream `:input` fields come from the extracted path while the full handoff is context only. This prevents accidental task-path guessing, stale prose parsing, and divergent task identity across delegates.
