For `psi.history.git/status`, preserve untrimmed porcelain output and classify per line from the index/worktree slots: index slot non-space/non-`?` => staged; otherwise non-empty lines => modified. Keep tests for untracked paths with misleading names, real staged changes, and worktree-only tracked modifications.
