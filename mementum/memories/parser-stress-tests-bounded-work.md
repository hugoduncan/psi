✅ Parser and sanitizer stress tests should assert deterministic bounded work, not wall-clock timeouts. Task 231 replaced `future`/`deref` timeout regressions for many textual-tool-call markers with parser-work instrumentation and monotonic marker scanning. This makes CI failures explain the violated parser contract (rescanning/quadratic work) instead of flaking under machine load.

When bounded work cannot be observed without testing private helpers, changing production signatures, or asserting interactions, keep adversarial output cases in the default suite and move scaling protection to an explicit benchmark of the complete public path. Calibrate that benchmark against the known-bad revision: an assumed asymptotic threshold can still pass the defect. Interleave samples with an equal-size control and compare medians to isolate the suspect overhead from common scan cost and host variation. Wall-clock checks belong in this opt-in, known-bad-calibrated layer, not correctness tests.
