🔁 In multi-prompt workflow `:session` steps, prompt-group `:prompt-workflow` imports the markdown body for each turn, not that prompt file's frontmatter capabilities. When merging existing single-prompt steps into prompt groups, move the union of required `tools`, `skills`, and model/session config to the shared step-level session config, and add definition tests that lock those capabilities. Otherwise the merged workflow can silently drop load-bearing review skills/tools even though the prompt body text still looks unchanged.
