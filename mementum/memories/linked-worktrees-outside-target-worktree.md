🔁 Git linked worktrees created inside another repo’s main worktree are real untracked paths to that repo (`git status --porcelain` reports `?? worktrees/`). If a test fixture uses linked worktrees as merge sources, create them outside the target repo (for example beside it) and clean both roots. Do not “fix” dirty-tree false positives by making production dirty checks ignore arbitrary untracked directories: branch merge should still reject untracked target files/directories. Lock this with fixture-cleanliness tests before merge and cleanup tests through the actual `git/worktree-add` path.
