- [ ] Re-diagnose the root cause in design.md: the test ns already requires `[org.httpkit.client :as http-client]` and http-kit 2.8.0 is already declared in both root `deps.edn` and `extensions/dev-http/deps.edn`. The warning exists because `org.httpkit.client/get`/`post` are generated by the private `defreq` macro in http-kit's client.clj, so clj-kondo's analysis never registers the vars. Do not fix via a project-global `.clj-kondo/config.edn` `:unresolved-symbol` suppression: per `λ lint(f)` (fix > suppress(inline) > exclude ≫ suppress(global)) and `λ fix(bug)` (workaround ⇝ complexity), a global exclude would mask genuine unresolved-var errors elsewhere and create the false-negative noise the friction report itself cites.

Keep the change localized to the http-kit import (one rule cluster, minimal mechanism) rather than editing project-global `.clj-kondo/config.edn` for an http-kit-specific concern.
