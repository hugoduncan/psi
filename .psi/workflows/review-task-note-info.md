Ask yourself:
"What would the task to address the design-steps need to know about the work
 done in this slice?"

Append a minimalist entry to implementation.md to record important
information for subsequent slices or reviews.

What to add:
  - principles to maintain when addressing the added design-steps.
  - task information that doesn't belong in design.md, plan.md or steps.md,
    but helps with addressing the added design-steps.
  - paths to relevant project (non-task) files

Avoid adding duplicate information already in the task files.
